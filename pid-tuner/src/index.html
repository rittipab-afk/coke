ผลการตรวจ

OP vs PV

ถ้าเส้นเป็นรูปสี่เหลี่ยมด้านขนาน (OP ขยับแต่ PV ไม่ขยับ แล้วกระโดด) เป็นลักษณะของ valve stiction ถ้าเป็นวงรีเรียบๆ มักมาจาก tuning หรือ disturbance

Cross-correlation OP ↔ PV

Horch test: ถ้ากราฟสมมาตรรอบ lag 0 (even) = ไม่ใช่ stiction ถ้าเป็น odd (ค่าที่ lag 0 ≈ 0 และสองฝั่งกลับเครื่องหมาย) = สงสัย stiction

เลือกช่วง step test

ลากบนกราฟเพื่อเลือกช่วงที่ loop อยู่ใน MAN และมีการ step OP (ครอบคลุมตั้งแต่ก่อน step จน PV นิ่ง หรือหลาย step ก็ได้)

ค่าที่แนะนำ (หน่วย CENTUM)

    เปรียบเทียบค่าปัจจุบันกับค่าที่แนะนำ

    GM = gain margin (ควร ≥ 2) · PM = phase margin (ควร ≥ 45°) · Ms = max sensitivity (ควร ≤ 1.7, เกิน 2 = เสี่ยง) · คำนวณจาก model จึงแม่นเท่าที่ model แม่น

    Closed-loop simulation

    ครึ่งแรก: SP step · ครึ่งหลัง: load disturbance ที่ input ของ process · เส้นจางคือค่าที่แนะนำเมื่อ gain และ dead time จริงมากกว่า model 30% (ทดสอบความทนทาน)

    สมมติฐานที่ต้อง verify กับ manual CENTUM หรือ control engineer
    • คำนวณแบบ ideal (non-interacting) PID: MV = (100/PB)·[e + (1/TI)∫e dt + TD·de/dt] โดย e เป็น %span ของ PV และ MV เป็น % ถ้า MV ไม่ใช่ 0–100% (เช่น cascade ไป SV ของ loop อื่น) ต้องแปลง gain ตาม span ของปลายทาง
    • ใช้ derivative filter α = 0.1 ในการคำนวณ margin และบวก dead time เพิ่มครึ่งหนึ่งของ control period (ผลของการ sample)
    • Simulation ใช้ velocity-form PID (แบบเดียวกับ DCS) มี OP clamp 0–100% ไม่รวม noise, valve dynamics และ nonlinearity
    • Model แบบ FOPDT/integrating เป็นการประมาณเชิงเส้นรอบจุดทำงานที่ test ถ้าจุดทำงานเปลี่ยนมาก gain อาจเปลี่ยน
